# ESION WordPressテーマ

## 入れ方

1. この `game_ec_theme` フォルダを `wp-content/themes/` に入れます。
2. WordPress管理画面の「外観 → テーマ」で有効化します。
3. 管理画面に追加される「ゲーム」から商品を登録します。

## 商品データ

- タイトル：ゲーム名
- 本文：説明
- アイキャッチ画像：商品画像
- カスタムフィールド `game_price`：価格を数字で入力（例 `5000`）
- 「順序」：ランキング番号として使用

画像URLを文字列で登録したい場合は、カスタムフィールド `game_image` も使えます。

## 検索・並び替え

`store.php` が `keyword` と `sort` をGETで受け取ります。

- `ranking`：ランキング順
- `price_asc`：価格が安い順
- `price_desc`：価格が高い順
- `name_asc`：名前順

ゲーム投稿が0件の間は、デドバ・モンハン・サイバーの仮データが表示されます。

## 既存画像

以前使っていた画像を、次の場所へ入れてください。

- `images/デドバ-本.jpg`
- `images/モンハン-本.jpg`
- `images/サイバー-本.jpg`
